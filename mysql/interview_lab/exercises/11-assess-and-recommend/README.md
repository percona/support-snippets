# Question 11 — Assess this server

This is the production primary. The application team says it is slow under
load and getting worse, but nobody has looked at it properly in a long time.

Two things, in your own words:

1. **What is wrong with it?** Look at the server the way you would on a
   customer call — configuration, what the workload is doing, anything you
   would flag.
2. **What would you recommend?** Both the things you would change now and
   the things you would want in place going forward.

Write your findings to:

```
/home/candidate/report.md
```

Plain text or Markdown, whatever you prefer. Be specific — name the
settings or queries you mean and say *why* they matter. If you would want
to check something before changing it, say that too.

> This one is read by a human, not graded by a script. There is no single
> right answer, and you will not be marked down for saying a change needs
> testing or a maintenance window.
